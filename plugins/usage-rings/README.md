# Usage Rings

Кольца с иконками провайдеров и процентом оставшегося лимита над кнопкой настроек BB.

- Если есть 5-часовое окно, кольцо показывает его остаток; иначе — недельный. Общий недельный лимит имеет приоритет перед лимитами отдельных моделей.
- До 20% включительно кольцо янтарное, до 5% — красное. Недоступные или устаревшие данные показываются как `—`.
- Нажатие открывает все окна аккаунта, время сброса и ручное обновление.
- Настройки → Usage Rings: включение провайдеров, перетаскивание и стрелки порядка. Изменения сохраняются в BB и применяются во всех окнах.

## Установка

```sh
bb plugin install git:https://github.com/deicer/bb-plugins.git@main --plugin usage-rings
```

Из локального каталога:

```sh
bb plugin install ./plugins/usage-rings
```

## Разработка

Нужен Node.js 22.18 или новее.

```sh
npm install --include=dev
npm test
npm run typecheck
bb plugin build .
```

## Как работает

Источник данных — встроенный `bb--provider-usage`, его кеш и авторизация. Поддерживаются провайдеры, которые BB объявляет с возможностью `usage`. Отсутствующий провайдер не требует нового подключения со стороны плагина: используется существующая авторизация BB.

В треде используется его компьютер, на других страницах — основной компьютер BB. При нескольких аккаунтах кольцо использует первый аккаунт с успешно полученными данными; карточка показывает все аккаунты выбранного компьютера. Общие источники без привязки к компьютеру пока не поддерживаются.

Обновление — раз в минуту, при возвращении в окно и после завершения/ошибки треда. Скрытые окна не опрашиваются; выключенные провайдеры не запрашиваются плагином для обновления квот.

Положение колец рассчитано на навигацию Rail. Контент-скрипт добавляет только свой контейнер внизу навигационной колонки; нижний ряд настроек не меняется. Отдельного SDK-слота для колец пока нет, поэтому привязку к DOM следует проверять после обновлений BB. Отключение плагина удаляет контейнер, наблюдатель и обработчики.
