---
name: usage-rings
description: Настройка колец остатка лимитов провайдеров в боковой панели BB.
---

Настройки → Usage Rings: включение провайдеров и порядок колец (перетаскивание или стрелки). Показывается 5-часовой остаток, иначе недельный. Источник — встроенный Provider Usage и существующая авторизация провайдера. Кольца работают в навигации Rail. Ошибка или отключённый компьютер дают `—`, а не нулевой остаток. Для подробностей и ручного обновления нажмите кольцо.

В карточке Codex кнопка с билетом открывает сохранённые сбросы: количество, даты истечения и подтверждение использования. Нужен актуальный Codex CLI на выбранном компьютере. Не вызывай consumeReset для проверки и не применяй сохранённые сбросы без явной команды пользователя: они расходуются.
