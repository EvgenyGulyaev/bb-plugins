---
name: rail-folders
description: Иконки левого рейла BB, объединённые в папки; управление составом и порядком.
---

Rail Folders рисует левый рейл BB и позволяет складывать иконки в папки. На рейле папка — только иконка: имя видно в подсказке, доступном имени, шапке всплывающего списка и настройках. Клик по папке раскрывает участников, клик по участнику открывает панель (⌘/Ctrl — соседняя панель). Правый клик по иконке: «Новая папка…», «Добавить в папку», «Убрать из папки»; правый клик по папке: переименовать или удалить. «Новая папка…» открывает модалку с сеткой иконок BB и полем имени (по умолчанию «Папка») — после OK папка создаётся пустой. Переименование использует тот же выбор иконки.

Иконку можно перетащить мышью на папку — она станет участником; строку участника можно вытащить из списка папки на свободное место рейла — иконка вернётся в рейл. Скрытые одиночные иконки остаются в «Ещё», скрытые участники — внутри своей папки. Пункт «Настроить рейл…» в меню «Ещё» открывает встроенный редактор BB для скрытия и порядка одиночных иконок. Настройки → Папки рейла создают папки, меняют имя иконки BB и порядок.

Состояние хранится в kv-ключе `rail-folders`:

```json
{ "folders": [{ "id": "folder_ab12cd34ef56", "name": "Работа", "icon": "Briefcase", "itemIds": ["plugin-a/panel"] }], "order": ["__bb__/new-thread", "folder_ab12cd34ef56"] }
```

Меняется только через RPC плагина: `rail_state`, `folders_create`, `folders_rename`, `folders_set_icon`, `folders_delete`, `folders_add_item`, `folders_remove_item`, `folders_move`. После записи публикуется `rail-folders-changed`; открытые окна перечитывают состояние. Иконка принадлежит не более чем одной папке; удаление папки возвращает участников в рейл.

Ограничения: CLI-команд у плагина нет; имя иконки не проверяется (неизвестное показывается запасной иконкой); участники папки видны только во всплывающем списке; пропавшие из навигации BB иконки сохраняются в составе, но не рисуются; перетаскивание нативное (HTML5 DnD) и требует мыши.

Не переключай провайдер навигации и не меняй раскладку без явной просьбы пользователя. Откат на встроенный рейл: `bb settings ui set sidebar.navigationProvider navigation/rail`. Режим `__automatic__` выберет этот плагин снова, пока он включён.
