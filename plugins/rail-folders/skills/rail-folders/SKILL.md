---
name: rail-folders
description: Иконки левого рейла BB, объединённые в папки; управление составом и порядком.
---

Rail Folders рисует левый рейл BB и позволяет складывать иконки в папки. На рейле папка — только иконка: имя видно в подсказке, доступном имени, шапке всплывающего списка и настройках. Клик по папке раскрывает участников, клик по участнику открывает панель (⌘/Ctrl — соседняя панель). Правый клик по иконке: «Новая папка…», «Добавить в папку», «Убрать из папки»; правый клик по папке: переименовать или удалить. «Новая папка…» открывает модалку с сеткой иконок BB и полем имени (по умолчанию «Папка») — после OK папка создаётся пустой. Переименование использует тот же выбор иконки.

Иконку можно перетащить мышью на папку — она станет участником; строку участника можно перетащить внутри списка, чтобы поменять порядок, или вытащить на свободное место рейла — иконка вернётся в рейл. Папку можно перетащить на другую папку или на одиночную иконку — линия вставки покажет, встанет ли она до или после цели по половине высоты, поэтому папка встаёт между одиночными иконками. На свободное место рейла папка уходит в конец. Скрытые одиночные иконки остаются в «Ещё», скрытые участники — внутри своей папки. Пункт «Настроить рейл…» в меню «Ещё» открывает встроенный редактор BB для скрытия и порядка одиночных иконок. Настройки → Папки рейла создают папки, меняют имя иконки BB, порядок папок стрелками по общей последовательности рейла (папка перешагивает и соседние папки, и одиночные иконки) и порядок участников внутри каждой папки стрелками — это клавиатурная и a11y-альтернатива перетаскиванию.

Состояние хранится в kv-ключе `rail-folders`:

```json
{ "folders": [{ "id": "folder_ab12cd34ef56", "name": "Работа", "icon": "Briefcase", "itemIds": ["plugin-a/panel"] }], "order": ["__bb__/new-thread", "folder_ab12cd34ef56", "plugin-b/panel"] }
```

`order` — единый порядок рейла: id папок и якоря одиночных иконок вперемешку, каждая папка ровно один раз. Иконка без записи в `order` встаёт после якорных записей в порядке BB, папка без записи — в самый конец (защита). Старое состояние, где `order` содержал только папки, читается как есть: одиночные иконки идут следом, внешний вид не меняется.

Меняется только через RPC плагина: `rail_state`, `folders_create`, `folders_rename`, `folders_set_icon`, `folders_delete`, `folders_add_item`, `folders_remove_item`, `folders_move` (`{ id, direction }`, один слот по общей последовательности), `folders_reorder_items` (`{ id, itemIds }`, перестановка текущего состава), `folders_reorder` (`{ id, index }`, позиция в общей последовательности), `rail_set_order` (`{ order }`, полная новая последовательность; дубликаты и пустые id отклоняет zod, потерю папки — сервер). После записи публикуется `rail-folders-changed`; открытые окна перечитывают состояние. Иконка принадлежит не более чем одной папке; удаление папки возвращает участников в рейл.

Ограничения: CLI-команд у плагина нет; имя иконки не проверяется (неизвестное показывается запасной иконкой); участники папки видны только во всплывающем списке; пропавшие из навигации BB иконки сохраняются в составе, но не рисуются; перетаскивание нативное (HTML5 DnD) и требует мыши, порядок без мыши меняется стрелками в настройках.

Не переключай провайдер навигации и не меняй раскладку без явной просьбы пользователя. Откат на встроенный рейл: `bb settings ui set sidebar.navigationProvider navigation/rail`. Режим `__automatic__` выберет этот плагин снова, пока он включён.
